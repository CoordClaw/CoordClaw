# CoordClaw 入门使用教程

本教程通过一组截图，带你完成从安装 CoordClaw 到给 AI 团队派发第一个任务的完整流程。

> **前置重要提示**：安装 CoordClaw 前，宿主软件（OpenClaw 或其变体，如 qclaw）**必须先正常打开并完成环境初始化**，否则 CoordClaw 无法发现宿主软件。

---

## 步骤 1：安装 CoordClaw

双击仓库根目录下的 `start.bat` 开始安装 CoordClaw。

![步骤1：双击 start.bat 安装 CoordClaw](getting_tarted_tutorial/S1.png)

安装过程中会自动下载并安装 Web 依赖。

![步骤1.1：自动安装 CoordClaw 依赖](getting_tarted_tutorial/S1_1.png)

---

## 步骤 2：打开控制面板

安装完成后，启动服务，然后在浏览器中打开面板地址：

```
http://localhost:18790
```

![步骤2：安装完成后用浏览器打开面板 URL](getting_tarted_tutorial/S2.png)

---

## 步骤 3：进入安装向导

首次打开会自动跳转到安装页面（`install.html`）。选择界面语言后，点击「下一步」。

![步骤3：在安装页面选择语言并下一步](getting_tarted_tutorial/S3.png)

---

## 步骤 4：选择要安装的宿主平台

向导会扫描用户主目录下已发现的 OpenClaw 实例。勾选需要 CoordClaw 接入的宿主平台，然后点击「安装」。

![步骤4：勾选要安装的宿主软件后点击安装](getting_tarted_tutorial/S4.png)

---

## 步骤 5：完成安装并进入 CoordClaw

安装完成后，页面会提示「务必重启 OpenClaw（或变体）后再进入」。请先打开宿主软件，然后点击「进入 CoordClaw」。

![步骤5：打开宿主软件后点击进入 CoordClaw](getting_tarted_tutorial/S5.png)

---

## 步骤 6：启动宿主软件并加载 CoordClaw

以 OpenClaw 为例，启动宿主软件后，它会自动加载 CoordClaw 插件系统。

![步骤6：打开宿主软件，自动加载 CoordClaw](getting_tarted_tutorial/S6.png)

等待 Gateway 启动完成，日志显示 `Gateway ready` 后即可进入控制面板。

![步骤6.1：宿主软件启动完成，CoordClaw 加载完成](getting_tarted_tutorial/S6_1.png)

---

## 步骤 7：新建项目

进入控制面板后，等待右上角「数据流」和「Gateway」指示灯变绿，然后点击左侧「新建项目」。

![步骤7：进入控制面板，指示灯变绿后点击新建项目](getting_tarted_tutorial/S7.png)

按向导填写项目名称、选择团队模板并指定项目路径，完成项目创建。

---

## 步骤 9：查看当前项目与组织架构

进入当前项目页面后，可以看到项目基本信息、成员列表、词元用量等。点击成员数量后的组织架构图标，可查看团队结构。

![步骤9.1：当前项目页面，可查看项目信息、成员列表和语言切换](getting_tarted_tutorial/S9_1.png)

![步骤9.2：团队组织架构图](getting_tarted_tutorial/S9_2.png)

> 点击顶部语言切换按钮，可在中文与英文界面之间切换。

---

## 步骤 10：派发任务，启动团队协作

团队准备就绪后，就可以派发第一个任务了。

![步骤10：选择发送者身份和接收者，给团队发任务](getting_tarted_tutorial/S10.png)

### 10.1 选择接收者

在消息输入区选择消息的接收成员。

![步骤10.1：选择接收者](getting_tarted_tutorial/S10_1.png)

### 10.2 输入任务内容

选择发送者身份（如「王总 / CEO」）和接收者（如「陈默 / 产品经理」），输入任务描述后发送。

![步骤10.2：选择发送者与接收者并输入任务](getting_tarted_tutorial/S10_2.png)

### 10.3 Agent 开始响应

消息发送后，Agent 会读取未读消息并开始工作。例如产品经理会回复需求澄清。

![步骤10.3：Agent 回复需求澄清](getting_tarted_tutorial/S10_3.png)

### 10.4 用户确认需求

针对 Agent 提出的澄清问题，用户可直接回复确认。界面中的「词元用量」图标可点击查看统计图表（数据基于 CoordClaw 自身算法，仅供参考）。

![步骤10.4：用户回复需求确认，可查看词元用量](getting_tarted_tutorial/S10_4.png)

### 10.5 词元用量统计

点击词元用量图标后，可查看项目词元量的可视化图表与明细表格。

![步骤10.5：项目词元量统计 - 可视化图表](getting_tarted_tutorial/S10_5.png)

![步骤10.7：项目词元量统计 - 明细表格](getting_tarted_tutorial/S10_7.png)

### 10.8 项目目录结构

CoordClaw 会在项目目录下生成标准化的工作目录：`.data`、`01-review`、`02-formal`、`03-archive`、`04-code`、`temp`、`worklog` 以及 `项目章程.md`。

![步骤10.8：项目目录结构](getting_tarted_tutorial/S10_8.png)

### 10.9 Agent 工作记录

每个 Agent 都会在 `worklog/<成员名>/` 目录下生成任务清单（`tasklist-*.md`）和工作日志（`worklog-*.md`）。

![步骤10.9：Agent 工作目录](getting_tarted_tutorial/S10_9.png)

### 10.10 工作日志示例

打开工作日志，可以看到 Agent 对任务目标、当前阶段、下一步行动等的结构化记录。

![步骤10.10：Agent 工作日志示例](getting_tarted_tutorial/S10_10.png)

### 10.11 评审目录

Agent 产出的 PRD 等正式文档会进入 `01-review/<成员名>/` 目录，并保留版本迭代记录。

![步骤10.11：评审目录中的 PRD 版本](getting_tarted_tutorial/S10_11.png)

### 10.12 最终产出示例

随着多轮协作推进，团队最终会产出完整的交付物，例如下面的产品需求文档（PRD）。

![步骤10.12：最终产出的 PRD 文档](getting_tarted_tutorial/S10_12.png)

---

## 小结

通过以上步骤，你已经完成了：

1. CoordClaw 的安装与初始化
2. 宿主软件（OpenClaw / 变体）的接入
3. 第一个项目的创建
4. 向 AI 团队派发任务并观察协作过程

后续你可以继续观察消息流、切换消息已读状态、扮演任意成员身份进行干预，或调整 `team.json`、`team RULE.md`、`teamsoul.md` 来定制团队行为。
