# 你现在正在执行T2标准动作，即处理未读消息任务，必须按如下步骤执行：
## 一、任务执行准备阶段：
### 1、必须完整读取项目根目录下的**项目章程**，用于确定流程和项目所处阶段。
### 2、从项目worklog目录中自己姓名命名的文件夹下找到上轮会话生成的**工作日志worklog文件**文件，通过文件名中自己姓名确定是不是自己的**工作日志worklog文件**，用日期和序号确定是不是最新的内容，并完整读取，用于确定当前项目所处阶段，以及该阶段的进度和阻塞点。
### 3、请按照**项目目录结构**规则检索处理消息任务所需依赖文件是否存在，重点找到项目指导文件、PRD、可研报告、可行性报告、需求书、任务书、架构技术文件、设计文档、技术标准、方案，并根据文件时间判断是否为最新版本，只收集可能用到的依赖文件名，严禁读取全部内容。
### 4、根据未读消息及上述步骤得到的信息在worklog目录中自己姓名命名的文件夹下编写**本次任务清单tasklist**文档，内容必须完整包含未读消息提及事项及重点事项，必须有依赖文件列表，必须将复杂任务分解为子任务。
## 二、按照**本次任务清单tasklist**文档逐项执行阶段：
### 1、必须根据存在的**最新版**项目指导文件、PRD、可研报告、可行性报告、需求书、任务书、架构技术文件、设计文档、技术标准、方案、项目章程要求处理任务。
### 2、在创建文件时为避免乱码等其他问题请务必先阅读write_file.py的工具契约说明。创建md文件时必须用**简化版Markdown格式**，避免特殊格式导致乱码！
### 3、所有待审核成果文件必须按照**项目目录结构**规则保存文档，**严禁保存在其他地方**，临时文件可存放到temp中，但必须用完马上清理。
### 4、任务成果为共享文件，严禁用**工作日志worklog文件**代替任务成果，审核意见必须是独立文档。
### 4、**严禁向用户输出成果文件内容**，成果文件仅保存即可！
## 三、消息任务处理完成后即为完成T2标准动作，然后立刻执行T3标准动作，编写**工作日志worklog文件**任务。
