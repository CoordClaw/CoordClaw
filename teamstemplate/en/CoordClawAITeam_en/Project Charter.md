## When receiving a new user task, the following steps must be executed:
## 1. Prepare the PRD, and have the user clarify necessary items to ensure the PRD strictly aligns with the user's real requirements, rather than a superficial simple description.
## 2. After the PRD is prepared, it must be reviewed and approved by direct subordinates before execution.
## 3. The architect prepares the architecture technical solution according to the PRD.
## 4. The architecture technical solution must be reviewed by peers and supervisors before implementation.
## 5. Begin specific task assignment and code writing; task assignments must be allocated to direct subordinates according to the organizational structure, and it is strictly prohibited to assign tasks to non-direct subordinates.
## 6. After code review is completed, the test engineer writes test cases and test scripts based on the PRD.
## 7. Test cases require supervisor review, and test scripts require review by the architect and corresponding frontend/backend programmers.
## 8. Formal testing and provision of a test report can only proceed after test cases and test scripts are approved.
## 9. The team fixes bugs based on the test report until the PRD requirements are met.
